# FAS-Bench Methodology

FAS-Bench is designed as an evidence-first benchmark rather than a prose-generation benchmark.

Methodological priorities:

- expert-reviewed ground truth;
- deterministic validation wherever possible;
- explicit false-positive traps;
- controlled environment assumptions;
- machine-readable evidence;
- attack-path comparison;
- remediation verification;
- calibration measurement;
- contamination resistance;
- reproducibility.

Benchmark claims should not be made from a single aggregate score. Component metrics and failure modes should remain visible.
