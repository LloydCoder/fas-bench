# Phase 10 — Governance

Benchmark changes are governed by five review dimensions:

- case/security objective review;
- oracle/ground-truth review;
- security review;
- reproducibility/integrity review;
- release approval.

Material changes to a case, oracle, schema, scoring policy, evaluator, harness, or mutation operator require a rationale, impact assessment, validation evidence, and changelog entry.

Retirement records must preserve retirement reason, release in which the case was retired, replacement case where applicable, and affected historical releases.

No governance record should contain credentials or unnecessary personal information.
